# Statement of Work (SoW)

## 1. Project Name
Smart Classroom – Web-Based Teaching Tool

## 2. Project Objective
Develop a simple, mobile-friendly web application that improves attendance management, classroom interaction, and AI-assisted learning.

## 3. Project Scope
- Attendance registration using QR codes and CSV export.
- Classroom people counting using YOLOv8.
- Student feedback and suggestions.
- Real-time polls.
- AI-generated lecture summaries.
- LLM-based homework reviews and anonymous comparisons.

## 4. Project Deliverables
- README and Technical Tools Report.
- SRS and Use Cases.
- Software Architecture.
- Class and Sequence Diagrams.
- Testing Strategy.
- Functional Web Application Demo.
- Project Conclusions.

## 5. Project Constraints
- Follow the KISS principle.
- Support smartphones and computers.
- No integration with Moodle or Zoom required.
- Reuse existing tools and AI technologies.
- Prioritize software design.
- Prepare a 10-minute classroom demonstration.

## 6. Expected Results
A functional Smart Classroom prototype demonstrating the main teaching features, with attendance management as the highest priority.
