# Statement of Work (SoW)

## 1. Project Name
Smart Classroom – Web-Based Teaching Tool

## 2. Project Objective
Design a simple and interactive web application that improves classroom learning, attendance management, and communication between students and lecturers.

## 3. Project Scope

The system will be designed to support:

- Automatic student attendance registration.
- Online and offline attendance spreadsheets.
- Classroom occupancy estimation using YOLO.
- Student feedback and suggestions.
- Real-time classroom polls.
- AI-based lecture summaries.
- LLM-based homework review and comparison.

## 4. Project Deliverables

- Technical Tools Report.
- Statement of Work.
- Software Requirements Specification (SRS).
- Use Cases.
- Software Architecture.
- Class and Sequence Diagrams.
- Testing Strategy.
- Functional Web Application Demo.
- Project Conclusions.

## 5. Project Constraints

- Follow the KISS principle.
- Support smartphones and computers.
- No required integration with Moodle or Zoom.
- Use existing software tools and libraries where possible.
- Prioritize software design over implementation complexity.
- Present a 10-minute classroom demonstration.

## 6. Expected Results

A simple and functional prototype demonstrating the main classroom features, with attendance management as the highest priority. Advanced AI features will be covered in the system design.
